# Face models

Weights for `@vladmandic/face-api` 1.7.15, copied unchanged from its `model/` folder:
SSD MobileNet v1 (detector), tiny face detector (live webcam frames), 68-point landmarks,
face recognition (128-number descriptors) and face expressions (the consent check's smile).

face-api and these weights are MIT licensed (see LICENSE); the weights originate from
justadudewhohacks/face-api.js, also MIT. They run entirely in the browser. Nothing is sent anywhere.
